# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

* Be kind. Be specific. Disagree with ideas, not people.
* Harassment, discrimination, and personal attacks are not welcome here.
* If you see something that violates this, file an issue or email the
  maintainer at the address listed in `pyproject.toml`.

Reports are handled privately and in good faith.
